# まるめる ひっぱる — NxPC.Live vol.80 インタラクティブポスター

NxPC.Live vol.80 のキービジュアルを、触って遊べる Web ページにしたものです。
ケーブルを引っ張る・丸める・柄を変える・別のソケットに挿し替える、といった操作ができます。
Three.js（WebGL）で描画しています。

- イベント: NxPC.Live vol.80（2026年12月5日）
- 会場: ソフトピアジャパンセンタービル ギャラリー2

---

## まず動かしてみる

`index.html` をダブルクリックで開いても動きません。ブラウザがローカルファイルからのスクリプトや画像の読み込みを止めるためです。
簡易サーバーを立ててから開いてください。

```bash
cd marumeru-hipparu
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。

- インストールは不要です。Three.js（0.170.0）とフォント（DotGothic16）はネット経由（CDN）で読み込むため、**インターネット接続が必要**です。
- WebGL が使えない環境では、代わりに `assets/poster.jpg` を表示します。

## フォルダ構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体。右上のボタン、スタイル、Three.js の読み込み |
| `main.js` | 3D シーン、ケーブルの物理、柄のシェーダー、操作、LED 掲示板、縦横レイアウト。ほぼすべての処理がここ |
| `assets/title-sdf.png` | タイトルロゴの形（距離場）。文字を伸ばす・膨らませる表現に使用 |
| `assets/title-front.png` | ケーブルより手前に描く文字（ま・め・っ・最後のる）のマスク |
| `assets/poster.jpg` | WebGL が使えないときの代替画像 |
| `tools/make_title_assets.py` | ロゴ画像から上の2枚の PNG を作るスクリプト |
| `tools/logo.webp` | 元のロゴ画像（背景透明） |

## できること（操作）

| 操作 | 動き |
|---|---|
| ケーブル・目玉をドラッグ | 引っ張ると細く伸び、離すとびよんと戻る |
| 長押し | その場所でくるくる丸まり、離すとほどける |
| タップ | タップした位置から柄が広がって変わる |
| プラグを別のソケットへドラッグ | 挿し替え。空いているソケットが光る |
| プラグを空中で離す | 目が生えて頭になる。頭をソケットに入れるとプラグに戻る |
| ノブを上下にドラッグ | 近くのケーブルがうねる |
| タイトル文字をドラッグ／長押し | 文字が伸びて戻る／ふくらむ |
| 「シャッフル」ボタン | 全ケーブルの柄をランダムに変える |
| 「もとにもどす」ボタン | 配線・柄・ノブを初期状態に戻す |

待機中は、数本のケーブルがゆっくりくねくね動き、動くケーブルが少しずつ入れ替わります。
OS の「視差効果を減らす」設定が有効な場合は、動きを控えめにします。

## レイアウトの考え方

画面の縦横比でレイアウトを切り替えます（`main.js` の `TALL` / `PORTRAIT`）。

- **横長**: 横長ポスター（2000×1125）の構図。四周に少し余白を取ります。
- **縦長（スマホ）**: 縦長デザイン（1416×2000）の構図。ロゴ2行、ケーブルは縦に高く立ち上がります。
- 画面を回転して縦横が切り替わると、ページを再読み込みしてレイアウトを作り直します。

座標はすべて **ポスター上のピクセル** で書いてあり、カメラの計算で 3D に変換しています（`ground()`、`atDepth()`）。

- 横長ポスター: 台の手前の縁が y=1045、奥の縁が y≈760
- 縦長デザイン: `fromDesign()` で横長ポスターの座標に変換

## よく調整しそうな場所（`main.js`）

| やりたいこと | 場所 |
|---|---|
| ノブ・プラグ・ソケットの大きさ | `PART_K`（横長は 0.86） |
| 台の大きさ | `PLINTH_W`, `PLINTH_D` |
| ケーブルの太さ（全体） | `WIDTH_K`（縦長 1.4 / 横長 0.86） |
| ケーブルごとの太さ・柄・つなぐソケット・形（横長） | `DEFS`。`w` が太さ、`pats` が柄、`a` / `b` がソケット、`pts` が通り道（ポスター座標） |
| ケーブルの形（縦長） | `PORTRAIT_SHAPES`（縦長デザインの座標。並び順は `DEFS` と同じ） |
| ソケットの位置 | `addSocket(...)` が並んでいるところ |
| ノブの位置 | `addKnob` に渡している座標の配列 |
| 柄のデザイン・色 | `RIBBON_FS`（シェーダー）の `pattern()`。色は先頭の定数 `ORANGE`, `BLUE` など |
| LED 掲示板の文字 | `LED_TEXT` |
| LED 掲示板の流れる速さ | フレーム処理内の `footerUniforms.uScroll.value += dt * 22`（22 = 1秒あたりの列数） |
| LED の色・背景色 | `buildFooter()` 内の `BOARD`, `OFF`, `ON` |
| 待機中に動くケーブルの数・入れ替わる間隔 | `wrigglers`, `updateWrigglers()` |
| 背景のグレー | `index.html` の `--bg`、`main.js` の `setClearColor` とタイトルシェーダー内の `vec3(.796)` |
| 白いケーブルを常に奥へ | `sortRibbons()` |

柄の番号は `P = { ORANGE, BLUE, GREEN, BANDS, CHECK, TEAL, SQUIG, WAVE, SPARK, TICKS, PALE, LOOP }` です。

## タイトルロゴを差し替える

1. 背景が透明なロゴ画像（PNG / WebP）を用意し、`tools/logo.webp` と差し替えます。「まるめる ひっぱる」を1行で横に並べた画像にしてください。
2. プロジェクト直下で次を実行します（Python 3 と numpy・scipy・Pillow が必要）。

   ```bash
   python3 tools/make_title_assets.py tools/logo.webp
   ```

3. `assets/title-sdf.png` と `assets/title-front.png` が上書きされます。

ケーブルの手前に出す文字は、スクリプト冒頭の `FRONT` で変えられます。
実行すると、検出した文字のかたまりが左から番号付きで表示されるので、その番号を指定します。

ロゴの縦横比が大きく変わる場合は、`main.js` の `SDF_CROP`・`WORDS`・`layoutTitle()` の数値も合わせて調整が必要です。

- 描画は1枚の WebGL キャンバスです。ボタン以外の要素はすべてキャンバス内に描いています。
